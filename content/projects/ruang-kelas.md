# Overview

A two-sided mobile app that connects teachers and parents — attendance, grades, assignments, notes and messages — in one shared daily view of every child.

![Teacher app and Parent app screens shown side by side.](/images/portfolio/ruang-kelas/overview.webp)

## Role & Responsibilities

As the **Mobile UI/UX Designer**, I designed both the Teacher and Parent apps end to end: information architecture, screen structure and user flows, interaction patterns and screen states, UI in the Plus Jakarta Sans system, data visualisation (attendance, grade trends), a shared component and status system, and developer-ready handoff.

The team owned product scope and school requirements, backend/data/sync, roles and permissions, and the web admin console.

## Problem & Goals

A homeroom teacher is busy and mobile — taking attendance, grading and posting updates for 30+ students between classes; every task has to be fast. A parent wants a calm, clear window into their own child — present or not, how grades look, what's due, what the teacher said — without digging.

**Goal:** Serve two opposite mindsets (input-heavy vs. read-and-reassure) with one consistent system, so both sides feel like the same product.

**How might we** let teachers record a class day in a few taps, and give each parent a clear, trustworthy view of their own child — from one shared system?

## Process & Design Decisions

Information architecture first — two apps built from the same components, navigation and status language. Then both flows, interaction design and screen states, data visualisation, a shared component system, and developer handoff.

Four key UX decisions:

1. **Attendance in a few taps** — one scrollable class list with one-tap Present / Excused / Absent, a live count and a clear Finish.
2. **A parent's calm daily view** — a home scoped to one child.
3. **Data that reassures, not overwhelms** — attendance donut, five-week grade trend, colour-coded status.
4. **Feedback kept human and private** — teacher notes with clear visibility labels and a focused parent reply.

![Teacher attendance flow across four screens: open class, take attendance, confirm status, parent notified.](/images/portfolio/ruang-kelas/process.webp)

## Solution Highlights

One coherent product across two very different apps. A whole class marked in under a minute from the phone. A parent home scoped to one child: attendance at a glance, a grade trend, and a plain-language feed of the day's events. Lightweight visuals carry the story before any table does. Private teacher notes and a focused parent reply keep feedback personal and safe.

## Outcomes & Lessons (Qualitative)

This is a qualitative project with no access to user analytics, so the outcomes described here concern design clarity, consistency and scalability — **not measured performance improvements**.

The design establishes one coherent product across two apps: teachers can record a class day in a few taps; parents get a clear, reassuring view of their child; dense school data is made calmer through simple visuals; and one shared component and status system supports consistent, developer-ready handoff.

**Lesson:** Shared components and a consistent status language aren't limits — they're what let a two-sided product stay coherent, and what makes the classroom and home feel genuinely connected.
